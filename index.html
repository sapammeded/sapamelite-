Data disimpan di perangkat ini. Untuk membagikan ke perangkat personil lain tanpa biaya layanan, ekspor paket resmi lalu impor ke perangkat mereka. Sinkronisasi cloud otomatis belum diaktifkan pada build ini.

Tambah kumpulan kalimat

Masukkan satu kalimat per baris. Semua baris akan digabung sebagai satu paket yang dapat disalin sekaligus.

Paket tersimpan

Generator QR khusus

QR hanya berisi ID paket acak dan checksum, bukan teks kalimat. Scanner umum mungkin menampilkan kode ID tersebut, tetapi tidak langsung menampilkan isi kalimat.

JUDUL QR
QR akan tampil di sini
QR ID bukan enkripsi atau autentikasi kuat. Jika paket tidak ada di perangkat personil, QR tidak akan membuka konten sampai paketnya diimpor atau disinkronkan.

Scanner internal

Arahkan kamera ke QR yang dibuat QR INTEL. Izin kamera mungkin memerlukan HTTPS (misalnya saat aplikasi di-host di GitHub Pages).

Backup, restore, dan transfer

Ekspor file JSON untuk memindahkan paket ke HP personil. Impor akan menggabungkan paket berdasarkan ID dan meminta konfirmasi jika ada ID yang sama.

Saran operasional: admin membuat paket → ekspor JSON → kirim melalui saluran internal → personil impor → scan QR. Simpan file cadangan di lokasi aman.

Administrasi lokal

Mode admin lokal hanya untuk mengurangi perubahan tidak sengaja. PIN yang disimpan di browser bukan kontrol keamanan kuat dan tidak boleh dianggap sebagai autentikasi organisasi.

Catatan keamanan

  • QR berisi ID acak, bukan teks kalimat secara langsung.
  • Konten di browser tetap dapat diakses oleh orang yang menguasai perangkat atau memodifikasi aplikasi.
  • PIN lokal tidak setara dengan login aman di server.
  • Untuk sinkronisasi bersama dan pencabutan akses yang tepercaya, tambahkan backend gratis dengan autentikasi dan aturan akses server. Paket gratis dapat berubah dan tidak dijamin selamanya.
  • Library QR dimuat dari CDN saat online. QR generator dan scanner gambar membutuhkan library tersebut; setelah library berhasil dimuat, data paket tetap disimpan lokal. Kamera memerlukan dukungan browser.
